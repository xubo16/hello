# 我的小说

一个用来写小说的仓库。用 Markdown 直接写,不需要安装任何东西,打开文件就能开始。

## 目录结构

```
.
├── README.md        本说明
├── 大纲.md          故事大纲 / 梗概 / 分卷分章计划
├── 人物设定.md      人物、势力、世界观设定
└── 章节/            正文,每章一个文件
    └── 第01章.md
```

## 怎么开始写

1. 打开 `大纲.md`,写下你的故事梗概和大致走向。
2. 打开 `人物设定.md`,记录主要人物。
3. 到 `章节/` 里,从 `第01章.md` 开始写正文。新的一章就复制一个文件,按 `第02章.md`、`第03章.md` 命名。

## 小建议

- 每写完一段,记得提交一次:`git add . && git commit -m "第X章:写到……"`,方便回看和防丢。
- 章节文件名用两位数字(`第01章`、`第02章`)排序更整齐。
